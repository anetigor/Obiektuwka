Zadanie do wykonania:

1. Utwórz plik Ksiazka.java z klasą Ksiazka i trzema polami prywatnymi: tytul i autor typu String oraz liczbaStron typu int.
2. Dodaj konstruktor z trzema parametrami, który ustawia wszystkie pola. Użyj słowa this.
3. Dodaj gettery getTytul(), getAutor() i getLiczbaStron(). Tytuł i autor nie mają setterów.
4. Dodaj setter setLiczbaStron(int liczbaStron). Jeśli wartość jest większa od zera, zapisz ją w polu. W przeciwnym razie nie zmieniaj pola i wypisz komunikat Niepoprawna liczba stron: z podaną wartością.
5. Nadpisz metodę toString() tak, aby zwracała napis w formacie widocznym w ostatnim wierszu przykładu. Oznacz ją adnotacją @Override.
6. W pliku Main.java utwórz książkę „Pan Tadeusz” Adama Mickiewicza o 344 stronach, wypisz jej tytuł i autora getterami, a potem wywołaj setter najpierw z wartością −5, a następnie z wartością 352. Na końcu wypisz cały obiekt.

Kod źródłowy:
Klasa Ksiazka.java

Kliknij aby rozwinąć
public class Ksiazka {
    private String tytul;
    private String autor;
    private int liczbaStron;

    public Ksiazka(String tytul, String autor, int liczbaStron) {
        this.tytul = tytul;
        this.autor = autor;
        this.liczbaStron = liczbaStron;
    }

    public String getTytul() {
        return tytul;
    }

    public String getAutor() {
        return autor;
    }

    public int getLiczbaStron() {
        return liczbaStron;
    }

    public void setLiczbaStron(int liczbaStron) {
        if (liczbaStron > 0) {
            this.liczbaStron = liczbaStron;
        } else {
            System.out.println("Niepoprawna liczba stron: " + liczbaStron);
        }
    }

    @Override
    public String toString() {
        return "Ksiazka{tytul='" + tytul + "', autor='" + autor + "', liczbaStron=" + liczbaStron + "}";
    }
}

public class Main {
    public static void main(String[] args) {
        Ksiazka ksiazka = new Ksiazka("Pan Tadeusz", "Adam Mickiewicz", 344);

        System.out.println("Tytuł: " + ksiazka.getTytul());
        System.out.println("Autor: " + ksiazka.getAutor());

        ksiazka.setLiczbaStron(-5);
        ksiazka.setLiczbaStron(352);

        System.out.println(ksiazka);
    }
}
