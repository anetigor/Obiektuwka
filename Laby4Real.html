Utwórz plik SlabaReferencja.java z klasą publiczną SlabaReferencja i metodą main.
2. Utwórz obiekt napisu poleceniem new String("Raport z laboratorium") i zapisz go w zmiennej raport.
3. Utwórz słabą referencję slaba typu WeakReference do tego obiektu.
4. Poproś o odśmiecanie (System.gc()) i wypisz wynik slaba.get() z opisem 1. Silna referencja istnieje: .
5. Przypisz zmiennej raport wartość null, ponownie poproś o odśmiecanie i wypisz wynik slaba.get() z opisem 2. Po usunięciu silnej referencji: .
6. Uruchom program poleceniem java SlabaReferencja, a potem poleceniem java -XX: +DisableExplicitGC SlabaReferencja i porównaj wyniki.

Opis wykonanych prac:

Najpierw utworzyłem silną referencje do obiektu tworząc operator new String w nowo utworzonej klasie SlabaRegerencja. Gwarantuje to że obiekt trafi na stertę i będzie mógł zostać usunięty przez Garbage Collcetor.
Potem utworzyłem słabą referencje czyli obiekt WeakReference<String> która przechowuje

słabą referencję do utworzonego wcześniej napisu
Następnie Wywołałem odśmiecanie przy istniejącej referencji stosując System.gc()

W kolejnym kroku usunąłem silną referencje i zweryfikowałem słabą referencje, zmiennej raport przypisano null.

Wywołanie System.gc() zlikwidowało napis a metoda slaba.get() zwróciła null

Kod źródłowy:

Kliknij aby rozwinąć
import java.lang.ref.WeakReference;

public class SlabaReferencja {
    public static void main(String[] args) {
        String raport = new String("Raport z laboratorium");
        WeakReference<String> slaba = new WeakReference<>(raport);
        
        System.gc();
        System.out.println("1. Silna referencja istnieje: " + slaba.get());
        
        raport = null;
        System.gc();
        System.out.println("2. Po usunięciu silnej referencji: " + slaba.get());
    }
}

Wnioski:

Dzisiejsza instrukcja wykazała że Silna referencja chroni obiekt. Dopóki do obiektu w pamięci prowadzi chociaż jedna silna referencja, Garbage Collector nie usunie go ze sterty.
Ponadto Słaba referencja pozwala na dostęp do obiektu ale nie chroni go przed usunięciem. Gdy znika ostatnia silna referencja obiekt wskazywany przez słabą referencja zostaje zlikwidowany przy najbliższym cyklu odśmiecania.

Wykazano również że Jawne wywołanie metody System.gc() w kodzie to jedynie sugestia dla maszyny wirtualnej Javy a nie gwarancja wykonania akcji.
