Zadanie do wykonania:

W pliku Oceny.java utwórz klasę NiepoprawnaOcenaException, która dziedziczy po Exception i ma konstruktor przyjmujący komunikat typu String.

2. W publicznej klasie Oceny napisz metodę statyczną sprawdzOcene(int ocena). Jeśli ocena jest mniejsza od 2 lub większa od 5, metoda rzuca NiepoprawnaOcenaException z komunikatem ocena spoza zakresu 2-5: uzupełnionym o wartość oceny. Zadeklaruj wyjątek w sygnaturze metody słowem throws.

3. W metodzie main sprawdź po kolei oceny z tablicy {4, 7, 3, 1}. Wywołanie sprawdzOcene umieść w bloku try, a w bloku catch wypisz komunikat wyjątku (metoda getMessage()).

4. Poprawne oceny policz w bloku try, a wszystkie sprawdzone oceny w bloku finally. Na końcu wypisz podsumowanie.

5. Uruchom program poleceniem java Oceny.java.

Opis wykonanych prac:

Najpierw utworzyłem klasę kontrolowanego wyjątku NiepoprawnaOcenaException dziedziczącą po Exception i przekazującą komunikat błędu do klasy bazowej.

Potem zdefiniowałem metodę sprawdzOcene, która waliduje, czy ocena mieści się w zakresie od 2 do 5, a w razie błędu rzuca zadeklarowany słowem throws wyjątek. Następnie w metodzie main przygotowałem testową tablicę ocen oraz pętlę weryfikującą każdą z nich.

W pętli użyłem bloku try do zliczania poprawnych wartości, bloku catch do przechwytywania wyjątku i wypisywania jego komunikatu bez przerywania działania programu, oraz bloku finally do zliczania absolutnie wszystkich sprawdzonych ocen.

Kod źródłowy:

Kliknij aby rozwinąć
class NiepoprawnaOcenaException extends Exception {
    public NiepoprawnaOcenaException(String message) {
        super(message); 
    }
}
public class Oceny {
    static void sprawdzOcene(int ocena) throws NiepoprawnaOcenaException {
        if (ocena < 2 || ocena > 5) { 
            throw new NiepoprawnaOcenaException(
                "ocena spoza zakresu 2-5: " + ocena); 
        }
    }
    public static void main(String[] args) {
        int[] oceny = {4, 7, 3, 1}; 
        int sprawdzone = 0; 
        int poprawne = 0; 
        
        for (int ocena : oceny) {
            try {
                sprawdzOcene(ocena);
                poprawne++;
                System.out.println("Ocena " + ocena + ": poprawna"); 
            } catch (NiepoprawnaOcenaException e) {
                System.out.println("Ocena " + ocena + ": błąd, " + e.getMessage()); 
            } finally {
                sprawdzone++; 
            }
        }
        System.out.println("Sprawdzono ocen: " + sprawdzone + ", poprawnych: " + poprawne);
    }
}

Wynik działania programu:

Wnioski

Wykonane ćwiczenia potwierdzają, że mechanizm wyjątków wykorzystujący instrukcje try, catch, finally oraz throw stanowi niezwykle skuteczne narzędzie do obsługi sytuacji awaryjnych bez przerywania działania całego programu.
Dodatkowo, tworzenie własnych typów wyjątków dziedziczących po klasach Exception lub RuntimeException ułatwia identyfikację i czytelne zgłaszanie specyficznych błędów w aplikacji. Prawidłowe działanie mechanizmów kontroli błędów można skutecznie weryfikować za pomocą testów jednostkowych JUnit, które wykorzystują asercje takie jak assertThrows do sprawdzania, czy program rzuca oczekiwane wyjątki w sytuacjach brzegowych.
Sam proces testowania ulega znacznej optymalizacji dzięki zastosowaniu testów parametryzowanych, co redukuje ilość powtarzalnego kodu poprzez weryfikację wielu zestawów danych wejściowych w obrębie jednej metody. Z kolei w przypadku sprawdzania klas korzystających z zewnętrznych zależności, kluczowe jest użycie biblioteki Mockito, która pozwala zastąpić te zależności kontrolowanymi atrapami i weryfikować interakcje między obiektami za pomocą metody verify()
