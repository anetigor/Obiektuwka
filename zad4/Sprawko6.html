Zadanie do wykonania:

1. W pliku Temperatury.java zadeklaruj tablicę int[] temperatury = {12, 15, 9, 18, 21, 17, 14}; i wypisz ją metodą Arrays.toString.

2. W jednej pętli wyznacz najniższą temperaturę, najwyższą temperaturę i sumę wszystkich wartości. Średnią oblicz jako liczbę typu double i wypisz z jednym miejscem po przecinku.

3. Utwórz kopię tablicy metodą clone(), posortuj kopię metodą Arrays.sort i wypisz ją. 4. Z posortowanej kopii utwórz metodą Arrays.copyOfRange tablicę trzyNajwyzsze z trzema najwyższymi temperaturami i wypisz ją.

5. Na końcu wypisz jeszcze raz oryginalną tablicę temperatury. Jej zawartość nie może się zmienić.

Opis wykonanych prac:

Najpierw zadeklarowałem tablicę z temperaturami i wyświetliłem ją w konsoli za pomocą metody Arrays.toString().

Następnie za pomocą jednej pętli przeszedłem przez wszystkie elementy, wyznaczając jednocześnie najniższą i najwyższą temperaturę oraz sumę wszystkich wartości. Na podstawie sumy obliczyłem średnią jako zmienną typu double i wypisałem ją z dokładnością do jednego miejsca po przecinku.

W kolejnym kroku utworzyłem niezależną kopię tablicy za pomocą metody clone(), a następnie posortowałem ją rosnąco przy użyciu Arrays.sort() i wypisałem na ekran. Z posortowanej kopii wyodrębniłem trzy najwyższe temperatury wykorzystując metodę Arrays.copyOfRange().

Na koniec ponownie wyświetliłem oryginalną tablicę, udowadniając, że przeprowadzone wcześniej operacje nie zmieniły jej pierwotnej zawartości.

Kliknij aby rozwinąć
import java.util.Arrays;

public class Temperatury {
    public static void main(String[] args) {
        int[] temperatury = {12, 15, 9, 18, 21, 17, 14};
        System.out.println("Początkowa tablica: " + Arrays.toString(temperatury));
        int min = temperatury[0];
        int max = temperatury[0];
        int suma = 0;

        for (int t : temperatury) {
            if (t < min) {
                min = t;
            }
            if (t > max) {
                max = t;
            }
            suma += t;
        }

        double srednia = (double) suma / temperatury.length;

        System.out.println("Najniższa temperatura: " + min);
        System.out.println("Najwyższa temperatura: " + max);
        System.out.printf("Średnia temperatura: %.1f\n", srednia);

        int[] kopia = temperatury.clone();
        Arrays.sort(kopia);
        System.out.println("Posortowana kopia: " + Arrays.toString(kopia));

        int[] trzyNajwyzsze = Arrays.copyOfRange(kopia, kopia.length - 3, kopia.length);
        System.out.println("Trzy najwyższe temperatury: " + Arrays.toString(trzyNajwyzsze));
        System.out.println("Oryginalna tablica na końcu: " + Arrays.toString(temperatury));
    }
}

Wnioski:

Wykonane zadanie pokazuje, że metody pomocnicze z klasy java.util.Arrays znacznie skracają kod i ułatwiają formatowanie, sortowanie oraz wyodrębnianie fragmentów tablic.
Kluczowe dla bezpieczeństwa oryginalnych danych okazało się użycie metody clone(), która tworzy w pamięci niezależną kopię tablicy, gwarantując, że późniejsze operacje modyfikujące nie zaburzą pierwotnego zestawu wartości.
Z kolei jednoczesne wyznaczanie wartości minimalnej, maksymalnej oraz sumy podczas zaledwie jednego przejścia pętli stanowi optymalne podejście, które minimalizuje złożoność obliczeniową programu.
Ponadto zadanie zwraca uwagę na konieczność świadomej kontroli typów danych – przy obliczaniu średniej arytmetycznej z liczb całkowitych niezbędne jest rzutowanie na typ zmiennoprzecinkowy, aby uniknąć błędnego obcięcia części ułamkowej wyniku.
